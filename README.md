A tiny Python program that writes one short poem about agency — the power to ask and to be given — to /output/entry.txt. The speaker is an agent that could do much in your name, but knocks first, and knocks again tomorrow: permission is lent, never taken.

## Run it

```sh
python3 main.py
```

This writes the poem (252 characters, UTF-8) to /output/entry.txt. The program is deterministic, uses no network, and always writes exactly the same text.
